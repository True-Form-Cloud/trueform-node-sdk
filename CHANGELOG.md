# Changelog

All notable changes to the Trueform Node.js SDK are documented here.

## [0.1.0] - 2026-08-13

- Added the `Trueform` client and `validations.create` resource interface.
- Added TypeScript declarations and separate ESM and CommonJS entry points.
- Added configurable retries, timeouts, cancellation, and typed errors.
- Added validation of successful API response shapes.
